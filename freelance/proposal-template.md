# Freelance Proposal Templates — Owusu Antwi

Portfolio: https://ooantwi.dev · GitHub: https://github.com/ooantwi

## Rules that win jobs

1. **First 2 lines are everything.** Clients see only a preview. Open with *their* problem, never "Hi, my name is…".
2. **Prove it with one relevant project** — link the exact case study, not the homepage.
3. **Ask one smart question** about their project. It shows you read the post and invites a reply.
4. **Keep it under ~180 words.** Short, specific, confident.
5. **End with a low-friction next step** (a quick call or a clarifying reply).
6. Never paste the template unchanged — fill every `[bracket]`.

## Main template (use for most jobs)

```
Hi [Client name, or skip if unknown],

You need [restate their core goal in one line — e.g. "a Flutter app that lets drivers
accept deliveries and track routes offline"]. I've built exactly this kind of thing.

Most relevant: [Project name] — [one-line result].
[Direct case study link, e.g. https://ooantwi.dev/projects/frankates-marketplace]

How I'd approach yours:

2. [Step 2 — e.g. build core flow first so you can test within week 1]
3. [Step 3 — e.g. polish, testing, store release / deployment]

Quick question: [one specific question — e.g. "Do you already have a backend,
or should I build the API too?"]

24 hours (GMT). Happy to jump on a 15-minute call to scope it.

Owusu
```
